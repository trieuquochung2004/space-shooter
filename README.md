🚀 Space Shooter Web Game

Chào mừng bạn đến với Space Shooter, một tựa game bắn súng không gian phong cách retro cổ điển được xây dựng bằng React, Vite, Tailwind CSS và HTML5 Canvas. Hãy bảo vệ dải ngân hà, tiêu chuẩn hóa các đợt tấn công từ kẻ địch thông minh, nâng cấp hỏa lực và đối đầu với Boss cuối cùng!

🌟 Tính năng & Các Task đã hoàn thành (Tuần 3)

[Task 15] Hệ thống Điểm cao (High Score): Tự động lưu trữ và đồng bộ Best Score của người chơi thông qua localStorage trên trình duyệt.

[Task 16] Trí tuệ nhân tạo Kẻ địch nâng cao:

Kẻ địch tốc độ cao (Fast Enemy): Di chuyển nhanh gấp đôi để tăng độ thử thách khi né tránh.

Kẻ địch lượn sóng (Zigzag Enemy): Quỹ đạo bay theo hình sin mềm mại, khó phán đoán và tiêu diệt hơn.

[Task 17] Hệ thống Cấp độ tăng dần (Level System): Độ khó tự động tăng theo mỗi 1000 điểm đạt được, tích hợp giao diện hiển thị Level theo thời gian thực.

[Task 18] Điều khiển cảm ứng trên Mobile: Giao diện tối ưu hoàn toàn cho thiết bị di động với các nút bấm ảo tinh tế (⬅, ➡, và nút BẮN).

[Task 19] Hệ thống Vật phẩm hỗ trợ (Power-Ups):

P (Power-Up): Bắn đạn chùm 3 hướng.

S (Shield): Tạo lớp khiên năng lượng bảo vệ tàu khỏi sát thương.

H (Health): Hồi phục máu cho người chơi (tối đa 3 HP).

X (Double Score): Nhân đôi điểm số khi tiêu diệt kẻ địch trong khoảng thời gian ngắn.

[Task 20] Triển khai ứng dụng (Cloud Deployment): Đã cấu hình và đưa game lên hoạt động trực tuyến qua nền tảng Vercel.

🎮 Hướng dẫn cách chơi

💻 Điều khiển trên Máy tính (Desktop)

Di chuyển: Sử dụng các phím W, A, S, D hoặc các Phím mũi tên (↑, ↓, ←, →).

Bắn đạn: Nhấn phím Space (Phím cách).

Tạm dừng / Tiếp tục: Nhấn phím P.

📱 Điều khiển trên Điện thoại (Mobile)

Sử dụng hai nút điều hướng ⬅ và ➡ ở góc dưới bên trái để lái tàu.

Chạm vào nút BẮN màu đỏ ở góc dưới bên phải để xả đạn.

🛠️ Hướng dẫn Cài đặt & Chạy dự án tại Local

Để chạy dự án này trên máy tính cá nhân của bạn, hãy thực hiện các bước sau:

Clone kho lưu trữ về máy:

git clone https://github.com/trieuquochung2004/space-shooter.git
cd space-shooter


Cài đặt các gói thư viện phụ thuộc:

npm install


Khởi động môi trường chạy thử (Development Server):

npm run dev


Mở trình duyệt web của bạn và truy cập vào địa chỉ: http://localhost:5173.
